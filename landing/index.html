Jak začít

Pět kroků, přibližně pět minut.

  1. Rozbalte workspace

    ZIP nebo git clone do C:\portableAI\. Funguje i jiná cesta.

  2. Spusťte setup

    pwsh -File scripts\Setup-DeepSeekStack.ps1 — nainstaluje nástroje lokálně do bin\npm-global.

  3. Doplňte API klíč

    Do env\.env vložte DEEPSEEK_API_KEY. Soubor je v .gitignore.

  4. Ověřte stav

    pwsh -File scripts\Test-Workspace.ps1 musí vrátit PASS.

  5. Spusťte agenta

    Menu nebo launcher\Launch-Reasonix.cmd. První prompt vezměte z prompts/00-system.md.

Když něco selže

Nejdřív troubleshooting, potom pwsh -File scripts\Test-Workspace.ps1 -Fix -WhatIf (náhled oprav) a teprve pak -Fix bez -WhatIf.
